# 🎰 로또 6/45 통계 기반 스마트 5게임 추천 생성기

동행복권의 실시간 최신 당첨 회차 데이터와 최근 당첨 통계를 기반으로, 출현 빈도수 가중치 추첨(Weighted Random Sampling) 알고리즘을 적용하여 최적의 5게임 조합(A~E)을 생성하는 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **통계 기반 5게임 자동 추출 (가중치 추첨 알고리즘)**:
   - $Weight(n) = \text{Count}(n) + \text{Base Weight}$ ($BaseWeight = 1$)
   - 최근 회차에서 자주 당첨된 번호일수록 확률 가중치가 높아지는 비복원 무작위 추첨 적용.
   - 한 번의 클릭으로 6개 번호 조합 5세트(A, B, C, D, E)를 오름차순 정렬하여 일괄 생성.

2. **제외 번호 및 고정 번호 설정**:
   - **고정 번호(Inclusion)**: 최대 5개까지 지정 가능 (추출 세트에 우선 배치 후 남은 자리를 가중치 추첨).
   - **제외 번호(Exclusion)**: 최대 10개까지 지정 가능 (1~45번 후보군에서 완전히 제거).
   - 상호 배타적 선택 제어 및 1클릭 초기화 지원.

3. **동행복권 실시간 당첨 정보 및 최근 회차 통계 연동**:
   - 동행복권 실시간 API 연동 및 Express 백엔드 프록시/캐시 서버 구성.
   - 최근 20회 / 30회 / 50회차 선택 분석 지원.
   - 1~45번 번호별 출현 빈도수 히트맵 및 출현 순위 차트 제공.
   - 자주 나온 번호(Hot Numbers TOP 5) 및 덜 나온 번호(Cold Numbers TOP 5) 한눈에 확인.

4. **실제 로또 공 색상 규격 적용 & 클립보드 원클릭 복사**:
   - 1~10: 노란색 (`#FBC400`)
   - 11~20: 파란색 (`#69C8F2`)
   - 21~30: 빨간색 (`#FF7272`)
   - 31~40: 회색 (`#AAAAAA`)
   - 41~45: 초록색 (`#B0D840`)
   - 5개 추천 게임 전체 원클릭 클립보드 복사 기능.

## 🚀 실행 방법

### 사전 준비
- Node.js (v20 이상 권장)

### 통합 실행 (서버 + 클라이언트 빌드 제공)
```bash
# 루트 폴더에서
npm start
```
웹 브라우저에서 `http://localhost:4000` 접속

### 개발 모드 실행
```bash
# 백엔드 서버 (4000번 포트)
cd server
npm start

# 프론트엔드 Vite 개발 서버 (3000번 포트)
cd ../client
npm run dev
```
